# Project 04 - Personal Portfolio (Capstone)

## Description
An authentic, responsive personal developer portfolio built from scratch using semantic HTML5, modern CSS3, and dynamic JavaScript DOM manipulation. It features a fully responsive layout, project showcase, skills grid, hobbies section, a contact form, and an interactive theme switcher.
